# Kyle's Voice

A free, open-source AAC (Augmentative and Alternative Communication) picture-card
app with speech synthesis. Android first; iOS later.

Built for a 10-year-old non-verbal autistic boy, and shared freely for anyone else
who needs it. There is no cost, no advertising, no subscription, no account, and
no data collection. Communication is not a premium feature.

## Status

Pre-development. Design and planning only. See [`docs/DESIGN.md`](docs/DESIGN.md).
