# Kyle's Voice

A free, open-source picture-card communication app with speech output, built for
a non-verbal autistic child and shared for anyone else who needs it.

No cost, no advertising, no subscription, no account, no tracking.

- [Privacy policy](privacy-policy.html)
- [For clinicians](FOR-CLINICIANS.html)
- [Source code on GitHub](https://github.com/pkellyuk/KylesVoice)
