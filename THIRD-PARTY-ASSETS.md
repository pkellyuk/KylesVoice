### What CC BY-SA 4.0 requires of us, and of anyone reusing this

- **Attribution.** Credit the authors above. The app shows this attribution in
  the symbol picker and ships the licence text alongside the artwork.
- **ShareAlike.** Any modified or derived symbols must be distributed under
  CC BY-SA 4.0 as well. Unmodified redistribution is unrestricted.
- **No additional restrictions.** We do not, and must not, place further limits
  on how the artwork may be used.

The symbols are used **unmodified**. If any are ever edited, the derivative must
carry CC BY-SA 4.0 and say what changed.

### Relationship to the GPL-3.0 application code

The artwork and the code are separate works distributed together. The code
remains GPL-3.0; the symbols remain CC BY-SA 4.0. CC BY-SA 4.0 is one-way
compatible with GPLv3, so relicensing the artwork under the GPL would be
permitted, but there is no reason to do it and it would obscure the artwork's
provenance. Keeping them separate is deliberate.

### Re-importing

The set is imported by script rather than copied by hand, so provenance is
reproducible:

```
git clone https://github.com/mulberrysymbols/mulberry-symbols.git
dart run tools/import_symbols.dart <path-to-that-clone>
```

### Known gaps

Mulberry is a large set, but it was designed with adult AAC users in mind and is
much stronger on nouns (2,973 of 3,436) than on core vocabulary. Several words a
first board commonly needs have **no symbol at all**: `yes`, `no`, `stop`,
`again`, `please`, `thank you`, `hurt` / `pain`, `mum` / `dad`, `like`.

This is why the emoji fallback is retained rather than removed, and it is
recorded for the speech and language therapy team in `docs/FOR-CLINICIANS.md`.

## Symbol sets deliberately not used

- **ARASAAC** — CC BY-NC-SA. The non-commercial clause is compatible with this
  app being free but complicates redistribution and downstream reuse, so it is
  not bundled. It remains a candidate for an optional in-app download.
- **PCS / Boardmaker, SymbolStix, Widgit** — proprietary. Not usable, and must
  never be imported.
